## ▶️ How to Run

### 1. Clone the repository

```bash
git clone https://github.com/saurabhsuman1515-netizen/FSD---SEM---3.git
```

### 2. Open the project

```bash
cd FSD---SEM---3
```

### 3. Run the frontend

You can open any `.html` file directly in your browser.

For example:

```text
index.html
```

For a better development experience, open the project in **Visual Studio Code** and use the **Live Server** extension.

### 4. Backend

Navigate to the backend directory:

```bash
cd project/backend
```

Then follow the setup instructions/dependencies defined inside the backend project.
